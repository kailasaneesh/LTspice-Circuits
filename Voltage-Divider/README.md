# Voltage Divider using LTspice

## Overview

This repository contains the LTspice simulation of a basic voltage divider circuit. It demonstrates how two resistors connected in series divide an input voltage to produce a lower output voltage.

## Circuit Details

- Input Voltage: 10 V
- R1 = 1 kΩ
- R2 = 1 kΩ

## Formula

Vout = Vin × (R2 / (R1 + R2))

## Simulation Results

| Parameter | Value |
|-----------|------:|
| Input Voltage | 10 V |
| Output Voltage | 5 V |
| Current | 5 mA |

The simulated output matches the theoretical calculation.
