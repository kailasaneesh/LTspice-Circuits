# RC Circuit using LTspice

## Overview

This repository contains the LTspice simulation of a basic RC (Resistor-Capacitor) circuit. It demonstrates the charging and discharging of a capacitor when a pulse voltage is applied.

## Circuit Details

- Pulse Voltage Source: 0–5 V
- Resistor: 2.34 kΩ
- Capacitor: 4.56 µF

## Simulation

Transient Analysis (`.tran 200ms`)

## Simulation Results

| Parameter | Value |
|-----------|------:|
| Input Voltage | 0–5 V (Pulse) |
| Output Voltage | Capacitor Voltage |
| Analysis | Transient (`.tran 200ms`) |

The simulated output demonstrates the expected charging and discharging behavior of the capacitor.
