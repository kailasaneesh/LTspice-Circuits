# LTspice Circuit Simulations

This repository contains a collection of basic circuits simulated using LTspice as part of my learning process.

## Contents

- Voltage Divider
- RC Circuit
- MOSFET as a Switch
- CMOS Inverter
- CMOS NAND Gate
- CMOS NOR Gate
- Half Adder
- Full Adder

Each circuit includes the LTspice schematic (`.asc`), circuit image (`.png`), and a README with a brief explanation.
